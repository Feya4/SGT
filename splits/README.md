`isic2018_lesion_split.csv` (columns include `image` and `split`) is the lesion-level ISIC 2018 split used in the
paper. Commit the file you trained with so that results can be reproduced exactly; it is regenerated by

    python preprocessing/make_isic_lesion_split.py --gt ... --groups ... --img_dir ...

`isic2018_near_duplicates_cross_lesion.csv` lists the near-duplicate pairs merged into one group.
BRACS uses the official split defined by the ROI image folders (see preprocessing/organize_bracs_official.py).
